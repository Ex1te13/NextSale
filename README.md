# NextSale — AI-агент повторных продаж для автосервисов (MVP)

NextSale находит в существующей клиентской базе автосервиса будущие сервисные возможности — по истории работ, интервалам обслуживания и заметкам механика — и помогает сервис-менеджеру превратить их в повторную запись.

> Менеджер открывает NextSale и получает готовую очередь клиентов для повторной продажи.
> **История → Opportunity → Сообщение → Запись → Выручка**

## Запуск

Нужен только Node.js 18+ — внешних зависимостей нет.

```bash
npm start
```

Откройте http://localhost:5173 и нажмите **«Загрузить демо-автосервис»**.

Автотесты по приёмочным тест-кейсам RTM:

```bash
npm test
```

## Что реализовано в MVP

Сквозная фича C-1…C-5 из PRD целиком: от импорта CSV до атрибутированной выручки.

| Кейс PRD | Что сделано | Требования |
|---|---|---|
| **C-1** Импорт CSV | Загрузка файла (drag & drop), проверка обязательных полей, ошибки с номером строки, повторная загрузка без дублей, демо-файлы | FR-01, NFR-02, NFR-05 |
| **C-2** AI Notes | Заметка механика → `service_type`, `due_date` / `due_interval`, `confidence`. Понимает «через 3 месяца», «через полгода», «через 5000 км», «к зиме», «весной». Неуверенный разбор → **Needs review**, такие записи не попадают в outreach. Есть «песочница» для проверки любой заметки | FR-02 |
| **C-3** Opportunity Engine | Правила интервалов по сроку и пробегу + deferred work из заметок. Из нескольких источников берётся ближайший срок, все источники сохраняются. Одна активная opportunity на клиента × авто × услугу. Expired для давно просроченных | FR-03, FR-04, FR-11 |
| **C-4** Очередь и outreach | Очередь «кому написать сегодня» с сортировкой и причиной позиции, карточка с объяснением (строка CSV, правило, срок, confidence), генерация черновика, Approve / Edit+Approve / Reject, отправка через один канал с idempotency key, имитация сбоя канала и retry, opt-out, cooldown | FR-05…FR-08, FR-12 |
| **C-5** Booking + Revenue | Фиксация записи (дата/время, изменение без дубля), Completed с выручкой (учитывается один раз), dashboard владельца с G-1…G-4 и воронкой, журнал событий без текстов сообщений | FR-09, FR-10, NFR-04 |

### Автотесты

`tests/acceptance.test.js` — 17 тестов, привязанных к тест-кейсам из RTM: TC-01…TC-12, TC-14, TC-16, TC-17 и guardrail cooldown.

TC-13 (нагрузка 50 пользователей), TC-15 (права разных организаций) и TC-18 (пилот) требуют серверной части и реального пилота — они относятся к следующему этапу.

## Ограничения MVP (честно)

- **AI Notes пока работает на правилах и словарях, а не на LLM.** Для демо это даёт детерминированный и объяснимый результат. Интерфейс экстрактора тот же, что нужен для LLM (`extractFutureWork(note, date) → {service_type, due_date, confidence}`), поэтому модуль можно заменить, не трогая остальную систему.
- **Канал отправки — демо.** Сообщения складываются во вкладку «Журнал → Исходящие», наружу ничего не уходит.
- **Данные хранятся в браузере (localStorage).** Сервера, авторизации и мультиарендности (NFR-01, NFR-03) пока нет.
- Интервалы обслуживания, порог confidence (70%), cooldown (14 дн.) и средний пробег (45 км/день) — предварительные допущения из SRS, они уточняются после пилота.

## Структура

```
index.html                  — приложение (открывается через npm start)
src/core.js                 — бизнес-логика: импорт, AI Notes, Opportunity Engine, outreach, метрики
src/app.js                  — интерфейс менеджера и владельца
src/styles.css              — стили
data/demo-history.csv       — демо-история автосервиса (20 клиентов, 25 визитов, 11 заметок)
data/demo-with-errors.csv   — файл с ошибками для проверки валидации (TC-01)
data/demo-data.js           — те же CSV, встроенные для браузера (npm run build:demo)
tests/acceptance.test.js    — приёмочные автотесты
scripts/serve.js            — локальный сервер без зависимостей
docs/                       — сценарий демо и текст для слайда
```

## Дальнейшее развитие

1. Backend (БД, авторизация, разделение данных организаций) — NFR-01, NFR-03.
2. LLM-экстрактор для AI Notes с fallback на текущие правила.
3. Реальный канал отправки (WhatsApp / SMS / email) и приём ответов клиента.
4. Пилот: ≥1 автосервис, ≥500 клиентов, 4 недели (TC-18).
