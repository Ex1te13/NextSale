## Правая колонка — «Что было сделано»

- Реализован сквозной цикл MVP: импорт истории из CSV → AI-разбор заметок механика → очередь «кому написать сегодня» → сообщение с подтверждением менеджера → запись → атрибутированная выручка.
- Создан Opportunity Engine: сроки по интервалам, пробегу и рекомендациям механика, дедупликация и объяснимость каждой возможности.
- Разработаны интерфейсы сервис-менеджера (очередь, карточка клиента) и владельца (dashboard метрик G-1…G-4).
- Добавлены защитные механизмы: отправка только после Approve, opt-out, cooldown, отсутствие дублей.
- Написано 17 автотестов по приёмочным тест-кейсам из RTM.
